# Copy & Tone

## Voice

Direct, confident, founder-to-founder. Short sentences. No agency speak, no buzzword soup, no "leverage synergies."

**Sounds like**: a senior engineer who ships and tells you the truth.

**Does not sound like**: marketing landing page generator, AI hype, corporate About Us.

## Patterns from portfolio

| Type | Example |
|------|---------|
| Hero split | "Software that ships. **Not slideware.**" |
| Eyebrow | "Envoy Direct — Independent software studio" |
| Lead | One sentence on who it's for + what they get |
| Section H2 | Plain statement: "What I take on", "Proof I ship" |
| CTA primary | "Start a project", "Send message", "Visit app" |
| CTA secondary | "View services", "Discuss yours" |
| Status | "Open for work", "Available", "Shipped" |
| Process promise | "Receive a Reply in Less Than 48 Hours" |
| Form success | "Message sent" + "You'll hear back within 48 hours." |

## CTA rules

- Verbs first: Start, Send, Visit, Create, Sign in
- Pair primary (filled) + secondary (outline) when two actions compete
- External app links: "Visit app" with `target="_blank"`

## Microcopy

- Errors: plain English, offer fallback email when API fails
- Empty states: honest ("Preview coming soon") not fake data
- Labels: sentence case — "Project type", not "PROJECT TYPE" (except eyebrows)

## Job platform copy (Indeed / Glassdoor familiarity)

Use labels users already know — don't rename for "AI brand":

| UI element | Copy |
|------------|------|
| Search CTA | "Search jobs" |
| Fields | "Job title, keywords, or company" / "City, province, or remote" |
| Sort | "Most relevant", "Date posted", "Match score" |
| Card actions | "Save", "View job", "Apply", "Easy apply" |
| AI eyebrow | "Resume-aware results" / "Resume-aware AI" |
| Match badge | "87% match" (not "Compatibility index") |
| AI summary label | "Role summary" — plain English, not "AI insight block" |
| Fit panel | "Strengths" / "Gaps" (not "Skill delta matrix") |
| Empty | "No jobs match yet" + concrete next step |
| Privacy | "Your data stays yours" + bullet specifics |
| Limits | "3 AI-powered searches per day" — honest, not vague |

Tone: calm, on-demand ("when you're ready to search"), not hypey AI marketing.

## Adapting for other apps

Keep structure, swap nouns:

- Portfolio: "founders who need working software"
- Job app: "roles that fit your experience" (RadarAI)
- Tool: lead with the job-to-be-done in one line

Do not copy portfolio content verbatim unless the app **is** Envoy Direct.
